🗄️ Backup your records

A backup is a safety copy of your business records, saved as a file on this phone. It works without internet, using what is already saved on the phone. If you stay offline for days or weeks, make a backup every few days and keep a copy somewhere else too (WhatsApp to yourself, Google Drive, a memory card).

Spreadsheet files you can open in Excel, Google Sheets or WPS.

ℹ️ Good to know

• The backup contains only what this phone has saved so far. Open the app with internet from time to time so everything is up to date and uploaded.

• Unsent changes are not lost by exporting — they stay on the phone until they upload.

• This file is a safety copy and a readable record of everything. It is not a one-tap restore: if records are ever lost, keep this file safe and it can be used to rebuild them.
