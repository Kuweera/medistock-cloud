# Handover template: each developer fills this in, in the OLD chat, before the chat is closed
Ask the developer: "Write DEVELOPER_n_HANDOVER_<date>.md with these sections, then stop." Then attach it to the NEW chat with the directive files, the repo ZIP and the Lead's contract (docs/DATA_CONTRACT_V19.md).
1. Role, owned files, files you must not edit.
2. What is finished and DELIVERED (zip names, what each contains, what is already in the repo).
3. What is finished but NOT yet delivered or not yet applied.
4. What you started and did not finish (exact functions and lines).
5. Decisions made by the Lead or owner that you rely on (quote them).
6. Open questions waiting for the Lead or owner.
7. Test status: verified (what ran, where), failed, not run. State if only an in-memory stand-in was used.
8. Known bugs and risks.
9. Exact next three steps.
10. Commands to run the tests and the browser checks.
First message in the new chat: "You are Developer n. Read your handover and the directive files. Do not start coding. Confirm the state from the repo ZIP, list differences you find, then continue from section 9."
